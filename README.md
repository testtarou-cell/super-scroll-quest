# SUPER SCROLL QUEST

オリジナルの横スクロールアクションゲームです。ブラウザだけで動きます（ビルド不要・依存なし）。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ローカルサーバー経由でもOKです。

```
npx serve .
# または
python3 -m http.server
```

## 操作

| 操作 | キー |
|---|---|
| 移動 | ← → （A / D） |
| ジャンプ | スペース （Z / W / ↑） |
| ダッシュ | Shift （X） |
| ポーズ | P / Esc |
| スタート・決定 | Enter |

スマホ・タブレットでは画面下にタッチボタンが出ます。

## ルール

- コインを集めながら右端のゴールの旗を目指します（制限時間300秒、残機3）
- 敵は踏むと倒せます。トゲ敵は踏めません
- `?` ブロックを下から叩くとコイン、`★` ブロックからはパワーベリーが出ます
- パワーベリーを取ると大きくなり、レンガブロックを頭で壊せるようになります（ダメージを受けると元に戻ります）
- コイン100枚で1UP

## 操作感のこだわり

- 加速・慣性つきの移動、空中でも細かく制御可能
- ジャンプはボタンを離すと高さが変わる可変ジャンプ
- コヨーテタイム（崖を離れて一瞬だけジャンプ可）とジャンプ先行入力
- カメラは進行方向を少し先読みして滑らかに追従
- パララックス背景、パーティクル、Web Audioの効果音

## 技術

- HTML5 Canvas + 素のJavaScript（単一ファイル、約1,100行）
- 画像素材なし：キャラクターや地形はすべてコード描画
- 音声ファイルなし：効果音はWeb Audio APIで生成
